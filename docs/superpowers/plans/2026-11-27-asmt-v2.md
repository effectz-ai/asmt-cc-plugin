# ASMT v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace ASMT's v1 workflow with a fork of Superpowers 7.0.2 exposed under `/asmt:*` names, configured by `docs` and `tests` keys, keeping `asmt-gate` and the PR guard.

**Architecture:** Port the chosen Superpowers files verbatim in one commit, then adapt them in later commits (renames, paths, config-aware behaviour). Bash tests under `tests/` cover the scripts and the plugin's shape; skill prose is checked by the shape test's greps and by review.

**Tech Stack:** Claude Code plugin (Markdown skills, JSON hooks), bash scripts, bash test files run by `tests/run-all`.

**Spec:** `docs/superpowers/specs/2026-11-27-asmt-v2-design.md`

- Check-by-hand: each task's report carries `Check by hand: <what to do, what to see>` or `Check by hand: none`; the build appends non-`none` items to `progress.md` as `Check by hand (Task N): ...`; `land` copies them into the PR body.

## Review Focus

1. A plan file not under `.asmt/work/` (e.g. a hand-written plan in `docs/`) — `sdd-workspace` must still give it a workspace, `.asmt/work/<plan-basename>/`, not fail. Test in Task 3.
2. Two plans both named `plan.md` in different topic folders — each must get its own folder's workspace, never share a ledger. Test in Task 3.
3. Running the build from inside a git worktree — the workspace must resolve to the main checkout's `.asmt/work/`, since the folder is git-ignored and absent in the worktree. Test in Task 3.
4. A stale cross-reference (`superpowers:x`, or `asmt:x` naming a skill that does not exist) silently breaks a handoff between skills. Shape-test check in Task 2.
5. SessionStart hook output that is not valid JSON (unescaped quote or newline in `using-asmt`) silently drops the bootstrap. Test in Task 4.
